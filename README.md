# South Bay STEM Association

Production Astro site based on the approved SBSA visual design. It builds as static HTML and is ready for Cloudflare Pages.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Cloudflare Pages settings:

- Build command: `npm run build`
- Output directory: `dist`
- Node version: `22`
